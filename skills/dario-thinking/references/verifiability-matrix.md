# 可验证度分级矩阵

Dario 反复强调："可验证任务我几乎确定 1-2 年内 AI 能做好；不可验证任务保留 5-10% 不确定性。"
对企业 AI 化来说，**可验证度决定方案能不能落地、推什么档位**。

## 一、三级标准

| 等级 | 定义 | 验证方式 | AI 化处方 |
|---|---|---|---|
| 🟢 高可验证 | 输出有客观对错，机器可判 | 测试用例 / 规则匹配 / 数据比对 | **全自动化**，无人工兜底 |
| 🟡 中可验证 | 输出有主观但可人工快速检查 | 人 5 秒能判断好坏 | **半 AI 化**，AI 生成 + 人工把关 |
| 🔴 低可验证 | 输出无客观标准，需长期验证 | 几周/几月才知效果 | **不做端到端 AI**，最多做信息辅助 |

## 二、30+ 任务样例分级

### 🟢 高可验证（直接全自动化）

| 任务 | 为什么高可验证 |
|---|---|
| 数据录入（PDF→Excel） | 数据对得上就是对的 |
| 订单匹配（找对应 SKU） | 有标准答案 |
| 合规检查（条款比对） | 有 checklist |
| 报表生成（按规则汇总） | 数字算得对就行 |
| 库存查询/更新 | 数据库有标准状态 |
| 邮件分类（按规则归档） | 类别明确 |
| 发票核对 | 字段对得上就行 |
| 单据 OCR | 识别准确率可量化 |
| 翻译（标准文档） | 有参考译文 |
| 代码 lint / 简单 bug 修复 | 测试能跑就对 |

### 🟡 中可验证（AI 生成 + 人工兜底）

| 任务 | 为什么中可验证 |
|---|---|
| 销售话术起草 | 人 5 秒能判断"这话能不能发出去" |
| 客服回复（非投诉类） | 有大致标准但需要语气把关 |
| 产品描述文案 | 风格对错明显 |
| 会议纪要整理 | 漏没漏关键点能查 |
| 周报/月报初稿 | 结构对不对一眼看出 |
| 简历筛选（一轮） | 明显不合适 vs 可能合适 |
| 合同条款拟稿（标准模板） | 律师 review 能判 |
| 内部知识库问答 | 答案对不对有据可查 |
| 工单分流 | 分对了 vs 错了能验 |
| 设计稿初版 | 客户看了能反馈 |

### 🔴 低可验证（不要做端到端 AI）

| 任务 | 为什么低可验证 | 替代方案 |
|---|---|---|
| 战略方向决策 | 几年才知对错 | AI 提供信息整合，人决策 |
| 高管招聘 | 长期才能验证 | AI 做初筛，人做面试 |
| 创意/品牌定位 | 主观，无标准 | AI 提供思路，人选 |
| 投资判断 | 长期回报才知 | AI 做尽调，人决策 |
| 客户关系维护 | 软指标，长周期 | AI 提供素材，人执行 |
| 复杂谈判 | 涉及人性、博弈 | 不动 |
| 敏感投诉处理 | 处理不当代价大 | 人做 |
| 法律辩论 | 涉及司法判断 | 人做（AI 辅助检索） |
| 危机公关 | 一次错全盘错 | 人做 |
| 文化建设 / 团队管理 | 不可量化 | 不动 |

## 三、识别技巧

遇到访谈里的某个任务，问自己 3 个问题：

1. **AI 做完后，多久能知道做对了？**
   - 5 秒 → 高可验证
   - 当天 → 中可验证
   - 一周以上 → 低可验证

2. **如果 AI 做错了，损失能不能挽回？**
   - 能（重做就行） → 可以全自动化
   - 不能（影响客户/品牌/法律） → 必须人工兜底
   - 灾难性（公司层面风险） → 不要做端到端

3. **不同人做这件事，结果会不会一样？**
   - 大体一样 → 高可验证
   - 风格不同但都行 → 中可验证
   - 因人差异巨大 → 低可验证

## 四、客户场景的常见混淆

⚠️ **客户经常以为是高可验证，其实是低可验证：**

| 客户以为 | 实际上 |
|---|---|
| "AI 帮我们做销售就行" | 销售涉及关系，是低可验证 |
| "AI 写文案就行" | 品牌调性是低可验证，要先有人定调 |
| "AI 替我决策" | 决策是低可验证，AI 只能提供信息 |
| "AI 处理客户投诉" | 敏感投诉是低可验证 |

⚠️ **客户经常以为是低可验证，其实是高可验证：**

| 客户以为 | 实际上 |
|---|---|
| "我们的报价很复杂" | 报价规则化后是高可验证（按 SKU+量+折扣计算） |
| "合同审查需要专业判断" | 标准条款比对是高可验证 |
| "数据处理我们靠经验" | 数据清洗规则化后是高可验证 |

**这两类混淆都是你的差异化机会**——指出客户没看清的可验证度，就是反共识发现。

## 五、写到方案里

在方案"战术层·改造点"部分，每个改造点都标可验证度：

```
改造点 X：合同初审 AI 化
- 可验证度：🟢 高可验证
- 处方：全自动化（Claude 读取 + checklist 输出 + 风险标记）
- 人工角色：律师只 review AI 标红的部分
- 置信度：⭐⭐⭐
```

```
改造点 Y：销售话术 AI 化
- 可验证度：🟡 中可验证
- 处方：AI 起草 + 销售选用 + 销售发送
- 人工角色：销售必须 review，AI 不直接对客户
- 置信度：⭐⭐
```
