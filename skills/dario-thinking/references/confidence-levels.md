# 分层置信度评级标准

Dario 在访谈里把所有预测都分层标置信度（90% / 50/50 / 5%）。
本 skill 的方案里**每个改造点都必须标置信度**——这是 Dario 思维最直接的体现。

## 一、三级评级标准

### ⭐⭐⭐ 高置信（确定能做成）

**满足条件（同时满足 3 条以上）：**
- ✅ 同行业有公开案例做成功了
- ✅ 用的是成熟工具栈（Claude / GPT / Coze / 飞书）
- ✅ 任务是 🟢 高可验证 或 🟡 中可验证
- ✅ 客户已有承接能力（数据 / 人 / SOP）
- ✅ 改造的是单一环节，不涉及组织变革

**典型场景：**
- 合同条款比对
- 报表自动生成
- 客服 FAQ 机器人
- 销售话术 AI 起草
- 内部知识库问答

### ⭐⭐ 中置信（大概率成，需验证）

**特征：**
- 技术成熟但客户场景适配性需验证
- 涉及多人协作或跨部门数据
- 客户的承接能力一般（需要边做边建）
- 任务有一定主观性

**典型场景：**
- 销售线索 AI 打分（依赖客户历史数据质量）
- 工单 AI 分流（依赖客户工单分类标准）
- 跨系统数据整合 + AI 报表（依赖数据接通）
- 客户画像 AI 生成（依赖数据丰富度）

### ⭐ 低置信（探索性，可能失败）

**特征：**
- 创新场景，行业没成熟案例
- 涉及 🔴 低可验证任务
- 端到端 AI Agent
- 涉及组织/流程重构

**典型场景：**
- AI Agent 端到端跑业务流程
- AI 主导决策类任务
- 涉及客户关系维护的 AI 化
- 复杂多模态场景（视频/语音/3D）

## 二、强制混搭原则

**一份方案不能全是 ⭐⭐⭐——这是画饼。**

正确比例（参考）：
```
全栈方案中的置信度分布：
├─ ⭐⭐⭐ 高置信：50-60% （第一阶段必须是这个等级）
├─ ⭐⭐ 中置信：30-40%   （第二阶段做）
└─ ⭐ 低置信：10-20%     （长期目标 / 探索性）
```

**如果你的方案只有 ⭐⭐⭐，意味着：**
- 你保守了，没给客户看到 AI 的更高潜力
- 或者你在画饼，把 ⭐⭐ / ⭐ 的事情都标成了 ⭐⭐⭐

**如果你的方案大多是 ⭐：**
- 客户会觉得不靠谱，不会签
- 应该先找几个 ⭐⭐⭐ 的快赢点建立信任

## 三、不同置信度的写法

### ⭐⭐⭐ 怎么写
直接说能做成，给数字预期，写明工具：

```
改造点：合同初审 AI 化 ⭐⭐⭐
- 工具：Claude + 飞书多维表格
- 预期：120 小时/月 → 30 小时/月（节省 75%）
- 落地周期：2 周
- 我们见过 X 家律所做过类似的，效果稳定
```

### ⭐⭐ 怎么写
说明前提条件 + 验证方式：

```
改造点：销售线索打分 AI 化 ⭐⭐
- 工具：Claude + 历史成交数据
- 预期：转化率提升 15-25%（区间，因为依赖数据质量）
- 前提：你们过去 1 年的成交数据要打标签
- 验证方式：先跑 50 条线索，对比人工打分准确率
- 如果验证通过 → 推广全量；如果不通过 → 退回手工
```

### ⭐ 怎么写
明说有失败风险 + 失败后怎么办：

```
改造点：AI Agent 端到端跑客户回访 ⭐
- 工具：Coze + Claude API + 飞书机器人
- 预期：完全释放 2 个客服人力（如果做成）
- 风险：AI Agent 端到端在中国市场尚无成熟案例
- 验证方式：先在 5% 流量上试 3 个月
- 失败止损：随时切换回人工，无业务损失
- 我们建议：6 个月内不押注这个，先用 ⭐⭐⭐ 的改造建立基础
```

## 四、置信度的常见误用

❌ **把工具成熟度当置信度**
"Claude 很厉害所以这件事 ⭐⭐⭐" — 错。工具厉害不等于场景能落地。

❌ **把客户期待当置信度**
客户想做的事不一定能做成。客户兴奋程度 ≠ 项目置信度。

❌ **把情怀当置信度**
"AI 应该能做这个" — 错。Should 不是 will。

❌ **躲在区间后面**
"可能 ⭐⭐⭐ 也可能 ⭐" — 错。逼自己选一档。

## 五、置信度和资源分配的对应

写完置信度后，用它来分配客户的资源/精力：

| 置信度 | 资源分配建议 | 时间窗口 |
|---|---|---|
| ⭐⭐⭐ | 优先投入 60-70% 资源，快速做透 | 第 1-2 个月 |
| ⭐⭐ | 投入 20-30%，边做边验证 | 第 2-4 个月 |
| ⭐ | 投入 10% 试错，不要 All-in | 第 4-6 个月 |

**这是 Dario 风格资源分配——非对称配置，不押注未验证的事。**

## 六、置信度需要随时调整

方案落地过程中，根据实际情况调整：

- 第一阶段做完，⭐⭐⭐ 项目失败 → 整体方案要回炉，可能客户场景特殊
- 第一阶段做完，⭐ 项目意外成功 → 加速推广，但仍要标⭐⭐
- 客户提供了新数据/资源 → 某些 ⭐⭐ 项目可以升到 ⭐⭐⭐

**置信度是活的，不是定死的。每月 review 一次。**
