# dedao-life-algorithms · 人生算法课

依据老喻《人生算法课》把个人成长和选择转成可观察的行动、反馈与概率问题，或整理学习练习。适合反思和小步试验，不给人生结果保证或替用户决定价值排序。

> 本目录为 `course_skill_contract: "2"` 格式的课程 skill，与 `~/.codex/skills/dedao-life-algorithms` 安装副本同源。同系列还有 `dedao-decision-algorithms`（《决策算法100讲》），未纳入本集合。
