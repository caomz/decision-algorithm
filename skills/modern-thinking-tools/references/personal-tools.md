# 个人与决策工具

这些是工具，不是人格标签。每次只加载和使用与主问题相关的小节，并用互补工具校正。

## 一、世界观与主体性

| 工具 | 解决什么问题 | 操作问题 |
| --- | --- | --- |
| 叙事 | 事实如何被串成因果、意义和行动方向 | 这是事实，还是一种故事？换一种叙事会改变什么行动？ |
| 重尾 | 少数极端结果支配总回报 | 怎样增加低成本尝试次数，并保留一次大上行？ |
| 能动性 | 从被安排、被驱使转向主动改变状态 | 哪个最小动作能让未来选择更多？ |
| 硬约束 | 先盘清资源、时间窗口、规律和他人的能动性 | 做得到吗、撑得住吗、失败时谁承担？ |
| 能耐寻求 | 优先选择能扩大未来状态空间的动作 | 这笔钱、这个职位或关系，是增加还是减少未来选择权？ |
| 可能性 | 接受未来并非唯一剧本 | 哪些仍未被事实关闭的可能性值得试？ |
| 三个自我 | 区分当下反应、对外身份和长期内核 | 我需要改情绪、改行为界面，还是更新底层模型？ |
| 供给侧心态 | 从争夺存量转向提供可验证价值 | 我能怎样降低协作摩擦、创造增量？ |
| 复利 | 选择可跨时间积累的资本 | 这个动作会积累金钱、能力、健康、关系、声望、心理或体验资本吗？ |
| 自我决定理论 | 诊断动机质量而不只看意志力 | 自主感、胜任感、关系感中哪一项被压住了？ |
| 自由能/对齐 | 在改自己、改环境、换环境之间选择 | 惊讶反复出现，是模型错、动作错，还是环境不匹配？ |
| WOOP | 把愿望编译成触发式行动 | 我想要 X，最可能遇到 Y；如果 Y 出现，我就做 Z。 |

### 硬约束补丁

硬约束用于给行动力过强的人降温，不是给拖延找借口。

- 四类约束：资源与能量、时间窗口、客观规律、他人的能动性。
- 先算关键账，不追求把一切精确建模。
- 区分真约束与假约束：能被一次谈判、学习或小试验改变的通常不是硬约束。
- 若“突破约束”本身需要科研、工程或制度创新，那已经是一个新主项目，不能当作原计划里的顺手步骤。

## 二、情绪、身份与长期感受

| 工具 | 解决什么问题 | 操作问题 |
| --- | --- | --- |
| 认知解耦 | 把感受、解释与事实拆开 | 我感到 X；我正在讲 Y 的故事；可观察事实是什么？ |
| 调用视角 | 防止只从自己镜头解释他人 | 对方、旁观者和一年后的我会分别看到什么？ |
| 认知重评 | 找到更有行动力而非更好听的解释 | 哪种解释既不否认事实，又能导向更好的动作？ |
| 身份认同 | 把身份从主体变成可选择的工具 | 这个标签是在描述我，还是在控制我？ |
| 安全感 | 区分稳定港湾与成长基地 | 我缺的是保护、可预期性，还是出去探索的底气？ |
| 共鸣 | 从控制和比较转向真实回应 | 哪些人、事、作品会让我被触动、能回应并发生改变？ |
| 目标函数 | 看清真正优化的东西 | 如果只允许保留一个长期方向，我希望宇宙奖励我什么？ |
| 二阶意愿/元表征 | 决定让哪个欲望支配行动，并跳出题目 | 我想要什么？我是否愿意成为一个被这个欲望控制的人？ |
| 副产品 | 处理幸福、睡眠、尊重、被爱等无法直取的目标 | 它背后的可直接追求对象是什么？ |
| 自我约束 | 用可信承诺换取信任和力量 | 我能主动放弃哪种短期自由，让别人敢于托付？ |
| 内部优化器 | 识别被 KPI、身份或习惯训练出的伪目标 | 这个模式只是做错，还是正在保护错误并排斥反馈？ |

## 三、概率、风险与选择

| 工具 | 解决什么问题 | 操作问题 |
| --- | --- | --- |
| 无免费午餐 | 不存在脱离场景的最优方法 | 我选择的领域和归纳偏置是什么？它在哪些场景会失效？ |
| 概率分布 | 决策控制过程，不控制单次结果 | 均值、方差、上下限、偏度和最坏尾部怎样？ |
| 因果模型/颗粒度 | 避免堆事实却没有机制 | 哪个最小模型能保留方向、量级和关键中介？ |
| 贝叶斯更新 | 用新证据修正信念 | 先验是多少？什么证据会显著改变它？ |
| 信息价值 | 过滤信息焦虑 | 这条信息会改变哪项动作？不会改变就停止搜集。 |
| 凯利思想 | 在可重复、乘法结算的游戏中控制仓位 | 即使有优势，投入多少才不会因一次失败出局？ |
| 非遍历性 | 区分群体平均与个人长期命运 | 这次损失会不会让我失去继续参与的资格？ |
| 反脆弱 | 寻找下行有限、上行开放的结构 | 怎样让波动暴露我的小问题，却不能摧毁我？ |
| 期权 | 保留权利而不提前承担义务 | 能否延迟承诺、分阶段买信息、保留 BATNA？ |
| 状态杠杆 | 找能改变后续成本和选择空间的一步 | 哪个上游、顺序或瓶颈动作会让后面全部更容易？ |
| 选择偏差 | 识别进入视野的样本不代表总体 | 哪些失败者、未发声者或未入选者被样本机制过滤了？ |
| 回归均值 | 不把极端波动误认成趋势或因果 | 这次好坏有多少可能只是随机波动？ |
| 前景理论 | 识别参照点和损失厌恶对下注的扭曲 | 我是在追求长期目标，还是只想回到旧高点？ |
| 参考类 | 用外部视角校正“我很特殊” | 相似背景的人通常得到什么分布，而非只看成功案例？ |
| 超级预测 | 让判断概率化、可检验 | 我愿意给多大概率？何时用什么结果复盘校准？ |
| OODA | 在变化中边做边学 | 当前最需要更新的是观察、定向、决定还是行动？ |

## 四、学习、职业与商业成长

| 工具 | 解决什么问题 | 操作问题 |
| --- | --- | --- |
| 主动高认知负荷 | 用有挑战的任务挤走走神 | 如何把被动浏览改成生成、判断或讲解？ |
| 认知负荷 | 尊重工作记忆窄门 | 哪些外在噪声可删？知识应拆成哪些图式？ |
| ICAP | 判断学习参与深度 | 能否从被动接收升级到主动、建构或互动？ |
| 刻意练习 | 用明确反馈修正可训练技能 | 这个领域是否成熟、能否获得导师、反馈和重复练习？ |
| 表征/图式/模型 | 把细节压缩成能预测和干预的地图 | 我能否不用原话解释机制，并预测一个新案例？ |
| 综合调研 | 在无教科书领域形成行动判断 | 当前要定位、结构化，还是生成新见解？ |
| 默会知识 | 学习无法只靠手册传递的现场判断 | 我需要去哪里“内居”、观察、模仿和复盘？ |
| 可取困难 | 用提取、间隔和交错增强长期记忆 | 这份困难是在促进学习，还是只制造痛苦？ |

| 赛道选择 | 先选游戏，再谈局部最优 | 这个结构奖励什么？我在谁的故事里，被什么放大？ |
| 场域 | 识别每个赛场的规则、筹码和裁判 | 这个场域如何定义“好”？我缺哪种被承认的资本？ |
| 经济租 | 区分创造价值与捕获价值 | 我创造的价值如何通过稀缺位置、接口或信任被保留？ |
| Alpha | 找到超出共识的认知与执行优势 | 我的错配洞察能否执行、占有并重构成长期优势？ |

| 机会窗口 | 判断需求、叙事与供给是否同时成形 | 类别是否出现？主导设计是否已锁定？现在早、正好还是太晚？ |
| 效果推理 | 在目标不清时从现有资源创造下一步 | 我是谁、我知道什么、我认识谁、输得起什么？ |
| 沃德利地图 | 把独特部分留给自己，把成熟部分外包 | 哪部分在创生，哪部分已商品化？ |
| 可托付性 | 把不确定性变成可交付秩序 | 我能否主动澄清目标、闭环反馈并稳定交付结果？ |
| 鲍莫尔成本病 | 看见真实人类时间会越来越贵 | 哪些服务无法提效，哪些人类判断反而会升值？ |
| 杰文斯悖论 | 识别效率提升后需求可能反而扩张 | 能力变便宜后，会释放哪些新需求和责任？ |

## 使用纪律

- 不把理论名称当证据；框架只能组织判断。
- 不因课程有某个概念就强行套用。
- 模型冲突时，以用户目标、现实证据、可逆性和反馈速度裁决。
- 任何工具若不能改变行动、信息需求或停止条件，就从回答中删掉。
