## GetNote 读取事实

当前 CLI 已认证。知识库元数据与普通笔记列表可用：

```bash
getnote kb 0Rp2K3pn --all -o json
getnote kbs -o json | jq '.data.topics[] | select(.topic_id == "0Rp2K3pn")'
```

本次实际详情 schema 为 `.data.note`，不是旧文档示例暗示的 `.data` 直出字段：

```bash
getnote note 1919271518504893552 -o json | jq '.data.note'
```

后续刷新必须先检查 `keys`，不得把 schema 漂移解析成空内容。

知识库语义召回应优先通过本 Skill 的合并器执行：

```bash
python3 skills/modern-thinking-tools/scripts/retrieve_evidence.py \
  --problem "职业转型但不想清零过去积累" \
  --query "运维转 AI 职业转型 过去积累" \
  --query "赛道选择 场域 复利 探索与利用" \
  --query "换赛道 误区 失败 问答" \
  --query "可逆实验 反馈 停止条件" \
  --stage discovery
```

Claude Code 从仓库外运行时使用 `${CLAUDE_SKILL_DIR}/scripts/retrieve_evidence.py`，不要依赖当前工作目录。

## 使用纪律

- 本 Skill 是概念提炼和应用路由，不是课程全文复制品。
- 只复述必要的短定义，其余用自己的话解释；用户要求引用时标明来源章节，不伪装成原创理论。
- 课程中的案例、数字和时事结论可能过时。若它们会影响现实建议，必须实时核验，不能因素材里出现过就当作当前事实。
- 观点材料只用于形成问题和反方，不自动升级为事实。
- 若后续知识库增加新笔记，按“相关性、证据等级、是否改变工具定义”三项筛选后再更新本 Skill。
